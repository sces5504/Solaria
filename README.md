# Solaria · 日蝕之後

幽暗史詩像素風俯視動作肉鴿。選擇劍士、弓箭手或法師，探索六重秘境，搭配元素專精、關卡試煉與傳奇裝備，挑戰各地形隨機出場的十八位三階段 Boss。

[開始遊玩](https://sces5504.github.io/Solaria/?v=3)

## 開始遊玩

直接用電腦瀏覽器開啟 `index.html`，不需安裝、編譯或網路。也可透過 GitHub Pages 遊玩。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | WASD／方向鍵 |
| 瞄準、攻擊 | 滑鼠、左鍵（可按住） |
| 職業技能 | 右鍵；弓箭手按住蓄力、放開發射 |
| 閃避 | 空白鍵 |
| 拾取裝備、開寶箱、進出口 | E |
| 背包與配裝 | I |
| 暫停 | Esc |
| 音效 | M |

清場開門，每第五區為 Boss 戰。掉坑扣最大生命 20%，存活會彈回安全地面。每次升級三選一；護甲、護符、戒指各一欄，背包十二格。死亡清空本局成長，最高分保存在此瀏覽器。

## 右鍵技能

- **劍士 — 日光反擊：** 短暫格擋正面攻擊；成功格擋立即強力反擊。沒有格擋成功時追加較弱斬擊。冷卻 4.2 秒。
- **弓箭手 — 穿雲蓄射：** 按住右鍵蓄力，放開發射高傷害貫穿箭；蓄力時移動較慢，暈眩或掉坑會中斷發射。冷卻 4.8 秒。
- **法師 — 共鳴引爆：** 游標方向最多 250px 的範圍引爆；已有狀態越多，傷害越高，並重新施加目前附魔。冷卻 5.5 秒。

詞條可縮短技能冷卻；傳奇可替技能附加水域、冰柱、星光彈等效果。左上方顯示技能就緒狀態與蓄力進度。

## 稀有度、詞條與掉落

普通灰色、魔法藍色、稀有紫色、傳奇金色。魔法一條、稀有兩條隨機詞條；傳奇兩條詞條加專屬機制。名稱、背包、穿戴欄、比較及地上物品統一使用稀有度顏色；傳奇落地有金色光柱。

普通怪裝備掉率 3%；第 2 區起每個小關卡至少一名精英，精英擊殺優先提供魔法以上裝備（50% 魔法、46% 稀有、4% 傳奇；受每輪上限限制）。普通區域寶箱有 25% 機率給裝備。每輪最多四件一般來源裝備，Boss 固定一件稀有以上（共最多五件）。第四區若此前完全沒掉裝，補給寶箱提供一件保底裝備。Boss 掉裝約 16% 為傳奇；三次 Boss 獎勵內若沒取得傳奇，第三次保底。

九種詞條：攻擊傷害、攻速、生命、暴擊、減傷、吸血、技能冷卻、元素持續時間、移動速度。每件不會抽到重複詞條，部分詞條限特定部位；穿脫不累加屬性。

六件一般傳奇：潮汐之眼（技能水域／額外感電連鎖）、逆焰披風（閃避留火）、雷行之戒（閃避放電）、赤月誓約（爆血回血）、白霜之心（技能冰柱）、星門環印（技能追加星光彈）。

## 戰鬥與補給

首輪 Boss 基礎生命從 540 提高為 2,400，後續每輪增加 40% 基礎生命，最高 19,200；敵人傷害仍維持原本上限。第二、三階段縮短招式間隔，保留預警、缺口與反擊窗口。普通敵人生命為初版的 1.35 倍（比 v2.1 降低約 27%），精英另為普通怪的 2.7 倍（比 v2.1 降低約 36%），移速 +12%、攻擊冷卻較短，帶有雷霆彈環、冰棘或餘燼追擊招式。

所有吸血來源的最終效果統一乘 0.1：生命虹吸每級 0.3%，虹吸戒指 0.4%，虹吸詞條約 0.15–0.3%；疊加上限 2.5%。赤月誓約每次爆血回血也從最大生命 5% 降為 0.5%。一般怪有 10% 機率掉落恢復 10 點的補血道具；Boss 補血掉落 15 點。每關寶箱恢復最大生命的 20%，至少 20 點；例如最大生命 100／150／250 時，分別恢復 20／30／50 點。補血道具必須走近，野外醫療只增加掉落補血道具的效果，寶箱不受影響。

小關卡從第二區起會隨機出現 0–2 個詞條；Boss 戰不帶詞條。上方會列出完整效果：疾行獵群（移速 +25%）、狂熱攻勢（攻擊冷卻縮短 20%，預警不變）、鐵血之軀（生命 +25%）、菁英巡獵（額外一名精英、不增加總怪數）、餘燼殘響（死亡留下預警火爆）、潮濕迷霧（敵方攻擊附加濕潤）。

## 升級與專精

升級池共有 **75 項**：原有 51 項職業、共通與專精能力，加上 24 項改變攻擊形式與觸發方式的進階能力。每局從升級最多學到火、冰、水、電中的兩種；流血獨立，裝備可補足其他元素。每次三選一最多出現一個尚未學會的主元素，以保留攻擊、技能和防禦的選擇。

拿到附魔後才提供對應專精；部分深入專精需要等級 4 或 6。包含水電弧網、雨幕、雷霆振幅、焚徑、深寒、冰柱、碎霜及流血累積／保留／爆發。職業增加格擋強化、斬決、閃避射箭、快速蓄力、彗星貫穿、引爆超載與持續星域等變化。已滿級、不適用及尚未解鎖的選項會排除；所有能力滿級後仍保留三項延續成長選擇。

元素視覺增加敵人間接力閃電、分支電弧、火焰命中火環與餘燼、冰晶爆散與大型冰柱、水波水花、血滴以及蒸汽霧團。視覺效果有數量上限，與遊戲亂數分開。

## 進階能力與稀有度

三選一使用藍色精良、紫色史詩、金色傳奇、紅色獨特。卡片標明觸發方式與效果；史詩偏向改變攻擊形式，傳奇偏向大範圍爆發／控制，紅色提供構築核心。進階元素必須先有對應附魔，等級 3 起出現史詩進階能力、4 起傳奇、6 起紅色。

紅色升級每局最多兩項，每次三選一最多一張紅色卡；若連續九次升級未出現紅色，且有符合條件的紅色能力，第九次保底提供一張。權重偏向藍色與紫色，已滿級、職業不適用或未滿足前置者不會抽到。

| 元素 | 進階能力與實際用途 |
| --- | --- |
| 雷電 | 左鍵超能雷槍、三次命中蓄電爆炸、被動追獵雷雲、右鍵雷霆君臨 |
| 火焰 | 左鍵扇形噴火、擊殺留火域、右鍵三枚火隕石、炎凰貫穿後爆燃火海 |
| 冰霜 | 左鍵冰河長矛、擊殺碎冰、右鍵絕對零度、被動永冬暴風雪 |
| 水 | 左鍵推敵水浪、追蹤水泡、右鍵拉怪漩渦、被動降雨加三向巨浪 |
| 流血 | 追蹤血刃、擊殺留血池、右鍵八向血鐮、伴隨追擊的血蝠 |

通用紅色核心：**死靈君主**（入場召幽魂、主攻擊擊殺補充，最多四隻）、**時隙主宰**（右鍵時停領域，減慢敵彈並短暫控制敵人）、**群星敕令**（右鍵七枚繼承附魔的星隕石）、**千影君王**（定期召職業分身）。

普通怪可短暫凍結，Boss 每次最多凍結 0.25 秒，之後有控制抗性。凍結也暫停尚未完成的敵方攻擊預警。漩渦與巨浪只位移普通怪。進階與召喚攻擊可施加元素，但不再觸發主攻擊進階，也不提供吸血；衍生擊殺不遞迴觸發留火／碎冰／再召喚。

火焰持續傷害現在隨玩家傷害成長；濕潤自身有輕度移速降低，水系專精可加強。敵人也遵守濕潤減速與火解冰規則。

## 六重秘境與十八位 Boss

每五區換一個地形，第五區 Boss 隨機從該地形三位守衛中挑選。再次遇到同地形時，不連續選到上次那一位；第六輪後地形循環。每位守衛有獨立外觀和三種主招式，並隨 65%／30% 生命進入第二／第三階段。

| 場景 | Boss 池與特色 |
| --- | --- |
| 暮色草原 | 苔冠古鹿（根刺與衝鋒）、裂影盜賊王（連續突進與匕首扇）、荊棘三頭蛇（三頭扇射與根系水池） |
| 幽冥地城 | 鎖鏈獄長（交叉光束）、白骨攝政王（侍從、掃骨光束與墓碑通道）、血鐘祭司（鐘波彈環與閉合光束） |
| 永夜冰原 | 白霜女王（冰柱缺口）、冰牙巨狼（多段衝鋒）、冰晶巨蟹（爪擊與十字霜線） |
| 腐敗之地 | 千瘡母巢（召幼體與腐池）、瘟疫巨蛾（螺旋孢粉與粉塵池）、深淵菌王（連續菌爆與觸手光束） |
| 燼火山脈 | 熔脈巨像（隕石與火牆）、灰燼炎龍（掃射龍息與連環隕火）、鍛爐暴君（旋轉重鎚與安全橫道） |
| 星空之境 | 星軌觀測者（螺旋星彈）、雙子星使（雙源扇射與相向光束）、虛空吞噬者（引力域與交織裂隙） |

轉階段清除該 Boss 的舊攻擊並留下反擊窗口。彈環有缺口、光束和衝鋒有方向預警，隕石和禮盒爆炸以實際覆蓋範圍預警。召喚數、排程、危險區與彈量都有限制。

## 隨機事件與紅色裝備

第二區起的小關卡約 28% 機率遇到六種事件之一。事件可以與原本 0–2 個關卡詞條共存，Boss 主戰不抽事件。入場時顯示大型提示，世界暫停 3.5 秒；點擊或按 Enter／空白鍵可提前開始。Esc 暫停及恢復會保留事件提示。

| 事件 | 規則 |
| --- | --- |
| 血月 | 額外四隻怪，生命 +18%、攻擊稍快；事件敵人總數最多 24 |
| 噩冬聖誕 | 加入邪惡聖誕老公公，擊敗固定一件紅色特殊裝備，仍須清除本關其他怪物 |
| 急凍天氣 | 入場凍結敵人四秒，每九秒再有寒潮；凍結期間敵人的蓄力也停止 |
| 流星雨 | 有一秒以上預警的中立隕石傷害雙方，清場額外十金幣 |
| 黃金巡遊 | 搬運者逃跑二十秒，擊敗得稀有裝備與額外金幣；逃走也不會卡住清場 |
| 月泉祝福 | 入場恢復 12% 最大生命，每八秒水波濕潤並傷害附近敵人 |

紅裝 **噩冬紅鈴**：右鍵三個冰霜爆發禮盒、閃避留禮盒；**暴雪聖冠**：右鍵召暴風雪、冰霜抗性與生命。兩件只由噩冬事件掉落，紅色名字與光柱；不混入一般裝備隨機池。事件裝備是本關額外獎勵，與普通掉裝上限分開。

## 元素反應

- **火：** 持續燃燒，也會移除冰霜減速。
- **冰：** 暫時減速。
- **水：** 施加濕潤。水命中燃燒目標，或火命中濕潤目標，產生蒸汽。
- **電：** 機率短暫暈眩；乾燥命中最多接力兩名敵人；濕潤目標增傷並最多接力五名敵人。每段從上一隻怪物繼續搜尋，電弧網可擴充目標數與距離。
- **流血：** 累積滿時爆血，不與元素交互。
- **蒸汽：** 敵我水火投射物相撞也會產生；預警後傷害雙方，請遠離範圍。

反應傷害不會自我觸發無限反應。Boss 對暈眩與爆血有額外限制。

## 計分

每區 100 分、普通／精英敵人 25 分、Boss 250 分、每枚金幣 10 分。Boss 不重複計入普通擊殺。金幣首版用於計分。

## GitHub Pages

發布來源設為 `main` 分支根目錄。遊戲網址：[Solaria](https://sces5504.github.io/Solaria/?v=3)。

所有圖像以 Canvas 即時繪製，音效以 Web Audio 合成。無外部素材、字型、服務或函式庫。開始遊戲後啟用音效；可按 M 靜音。開啟音效會播放確認聲，取消靜音、返回遊戲與鍵盤操作會重新啟動音訊；若顯示「音效 待啟用」，點擊即可重試。保留已儲存的靜音偏好，開始時若音效關閉會提示按 M 開啟。音量提高並限制同時音效數，已播放音效會釋放資源。背景分頁會自動暫停。

## 開發與驗證

遊戲邏輯使用固定 60Hz 更新。設定集中在 `CFG`、`UPG`、`GEAR`、`AFFIXES`、`MONSTERS`、`SKILLS` 與職業資料中。敵我彈量各有預算，水火攔截使用空間桶，視覺亂數與玩法亂數分離。測試腳本位於 `tests/`，詳細驗證紀錄見 `TESTING.md`。
