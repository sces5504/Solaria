# Solaria · 日蝕之後

原創像素俯視動作肉鴿遊戲。選擇劍士、弓箭手或法師，探索無限區域，搭配元素、升級與裝備，挑戰週期 Boss。

## 開始遊玩

直接用電腦瀏覽器開啟 `index.html`，不需安裝、編譯或網路。也可透過 GitHub Pages 遊玩。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | WASD／方向鍵 |
| 瞄準、攻擊 | 滑鼠、左鍵（可按住） |
| 閃避 | 空白鍵 |
| 拾取裝備、開寶箱、進出口 | E |
| 背包與配裝 | I |
| 暫停 | Esc |
| 音效 | M |

清場開門，每第五區為 Boss 戰。掉坑扣最大生命 20%，存活會彈回安全地面。每次升級三選一；護甲、護符、戒指各一欄，背包十二格。死亡清空本局成長，最高分保存在此瀏覽器。

## 元素反應

- **火：** 持續燃燒，也會移除冰霜減速。
- **冰：** 暫時減速。
- **水：** 施加濕潤。水命中燃燒目標，或火命中濕潤目標，產生蒸汽。
- **電：** 機率短暫暈眩；濕潤目標會承受額外傷害，向附近敵方連鎖。
- **流血：** 累積滿時爆血，不與元素交互。
- **蒸汽：** 敵我水火投射物相撞也會產生；預警後傷害雙方，請遠離範圍。

反應傷害不會自我觸發無限反應。Boss 對暈眩與爆血有額外限制。

## 計分

每區 100 分、普通／精英敵人 25 分、Boss 250 分、每枚金幣 10 分。Boss 不重複計入普通擊殺。金幣首版用於計分。

## GitHub Pages

發布來源設為 `main` 分支根目錄。遊戲預計網址：`https://sces5504.github.io/Solaria/`。

所有圖像以 Canvas 即時繪製，音效以 Web Audio 合成。無外部素材、字型、服務或函式庫。開始遊戲後啟用音效；可按 M 靜音。背景分頁會自動暫停。

## 開發與驗證

遊戲邏輯使用固定 60Hz 更新。設定集中在 `CFG`、`UPG`、`GEAR` 與職業資料中。測試腳本與操作說明位於 `tests/`，詳細驗證紀錄見 `TESTING.md`。
