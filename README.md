# Solaria · 日蝕之後

幽暗史詩像素風俯視動作肉鴿。選擇劍士、弓箭手或法師，探索六重秘境，搭配元素專精、關卡試煉與傳奇裝備，挑戰六個三階段 Boss。

[開始遊玩](https://sces5504.github.io/Solaria/?v=2.1.1)

## 開始遊玩

直接用電腦瀏覽器開啟 `index.html`，不需安裝、編譯或網路。也可透過 GitHub Pages 遊玩。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | WASD／方向鍵 |
| 瞄準、攻擊 | 滑鼠、左鍵（可按住） |
| 職業技能 | 右鍵；弓箭手按住蓄力、放開發射 |
| 閃避 | 空白鍵 |
| 拾取裝備、開寶箱、進出口 | E |
| 背包與配裝 | I |
| 暫停 | Esc |
| 音效 | M |

清場開門，每第五區為 Boss 戰。掉坑扣最大生命 20%，存活會彈回安全地面。每次升級三選一；護甲、護符、戒指各一欄，背包十二格。死亡清空本局成長，最高分保存在此瀏覽器。

## 右鍵技能

- **劍士 — 日光反擊：** 短暫格擋正面攻擊；成功格擋立即強力反擊。沒有格擋成功時追加較弱斬擊。冷卻 4.2 秒。
- **弓箭手 — 穿雲蓄射：** 按住右鍵蓄力，放開發射高傷害貫穿箭；蓄力時移動較慢，暈眩或掉坑會中斷發射。冷卻 4.8 秒。
- **法師 — 共鳴引爆：** 游標方向最多 250px 的範圍引爆；已有狀態越多，傷害越高，並重新施加目前附魔。冷卻 5.5 秒。

詞條可縮短技能冷卻；傳奇可替技能附加水域、冰柱、星光彈等效果。左上方顯示技能就緒狀態與蓄力進度。

## 稀有度、詞條與掉落

普通灰色、魔法藍色、稀有紫色、傳奇金色。魔法一條、稀有兩條隨機詞條；傳奇兩條詞條加專屬機制。名稱、背包、穿戴欄、比較及地上物品統一使用稀有度顏色；傳奇落地有金色光柱。

普通怪裝備掉率 3%；第 2 區起每個小關卡至少一名精英，精英擊殺優先提供魔法以上裝備（50% 魔法、46% 稀有、4% 傳奇；受每輪上限限制）。普通區域寶箱有 25% 機率給裝備。每輪最多四件一般來源裝備，Boss 固定一件稀有以上（共最多五件）。第四區若此前完全沒掉裝，補給寶箱提供一件保底裝備。Boss 掉裝約 16% 為傳奇；三次 Boss 獎勵內若沒取得傳奇，第三次保底。

九種詞條：攻擊傷害、攻速、生命、暴擊、減傷、吸血、技能冷卻、元素持續時間、移動速度。每件不會抽到重複詞條，部分詞條限特定部位；穿脫不累加屬性。

六件傳奇：潮汐之眼（技能水域／額外感電連鎖）、逆焰披風（閃避留火）、雷行之戒（閃避放電）、赤月誓約（爆血回血）、白霜之心（技能冰柱）、星門環印（技能追加星光彈）。

## v2.1.1 戰鬥與補給

首輪 Boss 基礎生命從 540 提高為 2,400，後續每輪增加 40% 基礎生命，最高 19,200；敵人傷害仍維持原本上限。第二、三階段縮短招式間隔，保留預警、缺口與反擊窗口。普通敵人生命為初版的 1.35 倍（比 v2.1 降低約 27%），精英另為普通怪的 2.7 倍（比 v2.1 降低約 36%），移速 +12%、攻擊冷卻較短，帶有雷霆彈環、冰棘或餘燼追擊招式。

所有吸血來源的最終效果統一乘 0.1：生命虹吸每級 0.3%，虹吸戒指 0.4%，虹吸詞條約 0.15–0.3%；疊加上限 2.5%。赤月誓約每次爆血回血也從最大生命 5% 降為 0.5%。一般怪有 7% 機率掉落恢復 10 點的補血道具；Boss 補血掉落 15 點。每關寶箱恢復 12 點生命，比 v2.1 的 6 點提高一倍。補血道具必須走近，野外醫療只增加掉落補血道具的效果，寶箱不受影響。

小關卡從第二區起會隨機出現 0–2 個詞條；Boss 戰不帶詞條。上方會列出完整效果：疾行獵群（移速 +25%）、狂熱攻勢（攻擊冷卻縮短 20%，預警不變）、鐵血之軀（生命 +25%）、菁英巡獵（額外一名精英、不增加總怪數）、餘燼殘響（死亡留下預警火爆）、潮濕迷霧（敵方攻擊附加濕潤）。

## 升級與專精

升級池擴為 **51 項**：18 項職業能力、18 項共通能力／附魔，以及 15 項元素或流血專精。每局從升級最多學到火、冰、水、電中的兩種；流血獨立，裝備可補足其他元素。每次三選一最多出現一個尚未學會的主元素，以保留攻擊、技能和防禦的選擇。

拿到附魔後才提供對應專精；部分深入專精需要等級 4 或 6。包含水電弧網、雨幕、雷霆振幅、焚徑、深寒、冰柱、碎霜及流血累積／保留／爆發。職業增加格擋強化、斬決、閃避射箭、快速蓄力、彗星貫穿、引爆超載與持續星域等變化。已滿級、不適用及尚未解鎖的選項會排除；所有能力滿級後仍保留三項延續成長選擇。

元素視覺增加敵人間接力閃電、分支電弧、火焰命中火環與餘燼、冰晶爆散與大型冰柱、水波水花、血滴以及蒸汽霧團。視覺效果有數量上限，與遊戲亂數分開。

## 六重秘境

每擊敗一輪 Boss，下一區切換場景；第六輪後循環。

| 場景 | 場景怪物 | Boss 與走位挑戰 |
| --- | --- | --- |
| 暮色草原 | 疾風狼、草原盜賊、流亡咒師 | 苔冠古鹿：根刺扇射、蓄力衝鋒、花瓣彈環 |
| 幽冥地城 | 幽城盾衛、連弩哨兵、鎖鏈術士 | 鎖鏈獄長：交叉光束、棋盤落刺、連續彈環 |
| 永夜冰原 | 霜牙狼、冰晶哨兵、雪原祭司 | 白霜女王：冰柱通道、延遲冰環、霜刃連射 |
| 腐敗之地 | 腐敗爬蟲、爆囊獸、孢子播種者 | 千瘡母巢：腐池、召喚幼體、缺口毒潮 |
| 燼火山脈 | 熔岩甲蟲、灰燼槍兵、火山巫師 | 熔脈巨像：隕石預警、旋轉火牆、衝鋒後火環 |
| 星空之境 | 星核游魂、虛空刺客、引力術士 | 星軌觀測者：雙向螺旋、旋轉交叉光束、連續星環 |

Boss 在 65% 與 30% 生命進入下一階段，轉階段清除自己的舊攻擊並留下短暫反擊窗口。環形預警標示缺口；衝鋒方向與光束有預警，招式會按階段交織。盾衛轉向有限速，側後方或攻擊後的破綻可以克服盾牌。

## 元素反應

- **火：** 持續燃燒，也會移除冰霜減速。
- **冰：** 暫時減速。
- **水：** 施加濕潤。水命中燃燒目標，或火命中濕潤目標，產生蒸汽。
- **電：** 機率短暫暈眩；乾燥命中最多接力兩名敵人；濕潤目標增傷並最多接力五名敵人。每段從上一隻怪物繼續搜尋，電弧網可擴充目標數與距離。
- **流血：** 累積滿時爆血，不與元素交互。
- **蒸汽：** 敵我水火投射物相撞也會產生；預警後傷害雙方，請遠離範圍。

反應傷害不會自我觸發無限反應。Boss 對暈眩與爆血有額外限制。

## 計分

每區 100 分、普通／精英敵人 25 分、Boss 250 分、每枚金幣 10 分。Boss 不重複計入普通擊殺。金幣首版用於計分。

## GitHub Pages

發布來源設為 `main` 分支根目錄。遊戲網址：[Solaria](https://sces5504.github.io/Solaria/?v=2.1.1)。

## 開發與驗證

遊戲邏輯使用固定 60Hz 更新。設定集中在 `CFG`、`UPG`、`GEAR`、`AFFIXES`、`MONSTERS`、`SKILLS` 與職業資料中。敵我彈量各有預算，水火攔截使用空間桶，視覺亂數與玩法亂數分離。測試腳本位於 `tests/`，詳細驗證紀錄見 `TESTING.md`。
