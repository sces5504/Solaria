# Solaria · 日蝕之後

幽暗史詩像素風俯視動作肉鴿。選擇劍士、弓箭手或法師，探索六重秘境，搭配元素專精、關卡試煉與傳奇裝備，挑戰各地形隨機出場的十八位三階段 Boss，再迎戰四階段的最終 Boss「索拉里斯・蝕日之王」。

[開始遊玩](https://sces5504.github.io/Solaria/?v=5.0.0)

## 開始遊玩

| 操作 | 按鍵 |
| --- | --- |
| 移動 | WASD／方向鍵 |
| 瞄準、攻擊 | 滑鼠、左鍵 |
| 職業技能 | 右鍵；弓箭手按住蓄力、放開發射 |
| 閃避 | 空白鍵 |
| 拾取裝備、開寶箱、進出口 | E |
| 背包與配裝 | I |
| 暫停 | Esc |
| 音效 | M |

清場先讓非裝備掉落飛向玩家，再依序進行三選一。普通寶箱恢復 10% 生命，區域 Boss 清場則恢復所有生命。每第五區為 Boss 戰。護甲、護符、戒指各一欄，背包十二格。死亡清空本局成長。

## 右鍵技能

- **劍士 — 日光反擊：** 短暫格擋正面攻擊；成功格擋立即強力反擊。沒有格擋成功時追加較弱斬擊。
- **弓箭手 — 穿雲蓄射：** 按住右鍵蓄力，放開發射高傷害貫穿箭；蓄力時移動較慢，暈眩或掉坑會中斷發射。
- **法師 — 共鳴引爆：** 範圍引爆；已有狀態越多，傷害越高，並重新施加目前附魔。

詞條可縮短技能冷卻；傳奇可替技能附加水域、冰柱、星光彈等效果。左上方顯示技能就緒狀態與蓄力進度。

## 升級與專精

升級池共有 **87 項**：原有 75 項能力，加上 12 項回血、護盾與危境防護升級。每局從升級最多學到火、冰、水、電中的兩種；流血不佔名額。元素共鳴卡為青綠色，標示最多兩種；主攻擊附魔只由升級取得，裝備不再提供主攻擊元素。每次三選一最多出現一個尚未學會的主元素，以保留攻擊、技能和防禦的選擇。

拿到附魔後才提供對應專精；部分深入專精需要等級 4 或 6。包含水電弧網、雨幕、雷霆振幅、焚徑、深寒、冰柱、碎霜及流血累積／保留／爆發。職業增加格擋強化、斬決、閃避射箭、快速蓄力、彗星貫穿、引爆超載與持續星域等變化。已滿級、不適用及尚未解鎖的選項會排除；所有能力滿級後仍保留三項延續成長選擇。

元素視覺增加敵人間接力閃電、分支電弧、火焰命中火環與餘燼、冰晶爆散與大型冰柱、水波水花、血滴以及蒸汽霧團。視覺效果有數量上限，與遊戲亂數分開。

## 進階能力與稀有度

裝備品質依進度由藍、紫、黃提高；橘色傳奇不受進度限制，紅裝來自事件或指定 Boss。

三選一使用藍色精良、紫色史詩、金色傳奇、紅色獨特。卡片標明觸發方式與效果；史詩偏向改變攻擊形式，傳奇偏向大範圍爆發／控制，紅色提供構築核心。進階元素必須先有對應附魔，等級 3 起出現史詩進階能力、4 起傳奇、6 起紅色。

| 元素 | 進階能力與實際用途 |
| --- | --- |
| 雷電 | 左鍵超能雷槍、三次命中蓄電爆炸、被動追獵雷雲、右鍵雷霆君臨 |
| 火焰 | 左鍵扇形噴火、擊殺留火域、右鍵三枚火隕石、炎凰貫穿後爆燃火海 |
| 冰霜 | 左鍵冰河長矛、擊殺碎冰、右鍵絕對零度、被動永冬暴風雪 |
| 水 | 左鍵推敵水浪、追蹤水泡、右鍵拉怪漩渦、被動降雨加三向巨浪 |
| 流血 | 追蹤血刃、擊殺留血池、右鍵八向血鐮、伴隨追擊的血蝠 |

普通怪可短暫凍結，Boss 每次最多凍結 0.25 秒，之後有控制抗性。凍結也暫停尚未完成的敵方攻擊預警。漩渦與巨浪只位移普通怪。進階與召喚攻擊可施加元素，但不再觸發主攻擊進階，也不提供吸血；衍生擊殺不遞迴觸發留火／碎冰／再召喚。

## 六重秘境與十八位 Boss

每五區換一個地形，第五區 Boss 隨機從該地形三位守衛中挑選。每位守衛新增各自代表彈幕，近戰型追擊與扇斬也更靈活。完成星空之境守衛後，先進入第 31 區最終決戰，通關並選擇下一週目才回草原。

| 場景 | Boss 池與特色 |
| --- | --- |
| 暮色草原 | 苔冠古鹿（根刺與衝鋒）、裂影盜賊王（連續突進與匕首扇）、荊棘三頭蛇（三頭扇射與根系水池） |
| 幽冥地城 | 鎖鏈獄長（交叉光束）、白骨攝政王（侍從、掃骨光束與墓碑通道）、血鐘祭司（鐘波彈環與閉合光束） |
| 永夜冰原 | 白霜女王（冰柱缺口）、冰牙巨狼（多段衝鋒）、冰晶巨蟹（爪擊與十字霜線） |
| 腐敗之地 | 千瘡母巢（召幼體與腐池）、瘟疫巨蛾（螺旋孢粉與粉塵池）、深淵菌王（連續菌爆與觸手光束） |
| 燼火山脈 | 熔脈巨像（隕石與火牆）、灰燼炎龍（掃射龍息與連環隕火）、鍛爐暴君（旋轉重鎚與安全橫道） |
| 星空之境 | 星軌觀測者（螺旋星彈）、雙子星使（雙源扇射與相向光束）、虛空吞噬者（引力域與交織裂隙） |

## 地形與最終決戰

所有飛行彈幕與雷射都會被牆擋住；沒有彈道的落雷、隕石類招式仍可指定牆後位置。劍、弓、法杖有各自可辨認的外觀。

草原湖泊只阻擋通行；地城、冰原沒有坑洞。火山熔岩每 0.4 秒扣血並燃燒，腐敗地面每 0.4 秒扣血，適用抗性與無敵規則；星空保留裂隙，墜落扣最大生命 20% 並返回最近安全地面。

**索拉里斯・蝕日之王**：第 31 區專屬「蝕日聖殿」，初始 12,000 生命。

1. **三道刻印：** 烈陽／寒月／星雷刻印維持王的無敵護盾，刻印有元素扇射，必須全部摧毀。
2. **烈陽審判：** 緩慢旋轉的審判光束、多波有缺口的彈環、留一條安全橫道的地面光束。
3. **萬象夜蝕（65%）：** 交叉轉動光束、火／水／電交織彈環、橫道結束後接火環。
4. **破曉終焉（30%）：** 八向蝕冠星陣與交織水雷曲線彈、追蹤位置火隕石與更快的交織招式；每次轉階段清除舊招式，保留預警與反擊窗口，生命門檻避免直接跳過階段。

## 隨機事件與紅色裝備

| 事件 | 規則 |
| --- | --- |
| 血月 | 額外四隻怪，生命 +18%、攻擊稍快；事件敵人總數最多 24 |
| 噩冬聖誕 | 加入邪惡聖誕老公公，擊敗固定一件紅色特殊裝備，仍須清除本關其他怪物 |
| 急凍天氣 | 入場凍結敵人四秒，每九秒再有寒潮；凍結期間敵人的蓄力也停止 |
| 流星雨 | 有一秒以上預警的中立隕石傷害雙方，清場額外十金幣 |
| 黃金巡遊 | 搬運者逃跑二十秒，擊敗得稀有裝備與額外金幣；逃走也不會卡住清場 |
| 月泉祝福 | 入場恢復 12% 最大生命，每八秒水波濕潤並傷害附近敵人 |

每個事件固定額外一件對應的紅色獨特裝備（聖誕擊敗事件 Boss 時掉，其餘清場掉）；重複結算不會再發一件。血月 **血月契印**（主攻擊擊殺爆血花）、急凍 **寒潮結晶**（右鍵凍結）、流星雨 **隕星核心**（右鍵三枚繼承元素的隕石）、黃金 **逐金羅盤**（金幣蓄能、右鍵消耗發追蹤星光）、月泉 **月泉聖杯**（右鍵月泉與少量回血）。

紅裝 **噩冬紅鈴**：右鍵三個冰霜爆發禮盒、閃避留禮盒；**暴雪聖冠**：右鍵召暴風雪、冰霜抗性與生命。兩件只由噩冬事件掉落，紅色名字與光柱；不混入一般裝備隨機池。事件裝備是本關額外獎勵，與普通掉裝上限分開。

## 元素反應

- **火：** 持續燃燒，也會移除冰霜減速。
- **冰：** 暫時減速。
- **水：** 施加濕潤。水命中燃燒目標，或火命中濕潤目標，產生蒸汽。
- **電：** 機率短暫暈眩；乾燥命中最多接力兩名敵人；濕潤目標增傷並最多接力五名敵人。每段從上一隻怪物繼續搜尋，電弧網可擴充目標數與距離。
- **流血：** 初始門檻 100；同一普通目標每次爆血後提高 50% 初始門檻，Boss／事件 Boss 提高 65%。抗性記在目標身上，新敵人重新起算；爆發有血色光暈、爆裂碎片、擴散圓環與震屏。流血不與元素交互。
- **蒸汽：** 敵我水火投射物相撞也會產生；預警後傷害雙方，請遠離範圍。

## 計分

每區 100 分、普通／精英敵人 25 分、守衛 Boss 250 分、事件 Boss 175 分、最終 Boss 1,500 分、每枚金幣 10 分。Boss 不重複計入普通擊殺。金幣首版用於計分。
